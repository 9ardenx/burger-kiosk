# 게시용 메뉴 사진

게시 규격은 **720 × 465px, JPG**입니다. 현재 매장 사진 7장의 게시용 복사본입니다. 원본 보관 폴더와 구분하며, 파일별 출처·크기·자르기 좌표·SHA-256은 `manifest.json`에 기록합니다.

- 기존 720×468 사진은 위아래 배경을 각각 1.5px, 720×480 음료 사진은 각각 7.5px 잘라 비율을 맞췄습니다. 가로세로를 서로 다른 비율로 늘리지 않습니다.
- 감자튀김은 2026-11-25 사용자가 제공한 [스크린샷](../sources/fries-screenshot-20261125.png)을 사용합니다. 바깥 흰 테두리와 둥근 모서리 안쪽의 사각형 영역을 추출한 뒤 720×465로 확대했습니다. 음식 내용을 생성하거나 바꾸지 않았습니다. 스크린샷이 413×281이므로 고해상도 원본보다 선명도는 낮습니다.
- 예전 서버 사진 7장은 [originals](../originals/)에 그대로 보존합니다. 이전 감자튀김 편집본도 상위 폴더에 남아 있습니다.

새 사진은 관리자 메뉴 등록/수정에서 선택합니다. 720×465에 맞도록 비율을 유지해 채우며 넘치는 가장자리는 잘립니다. 가로·세로 위치 조절로 음식이 잘리지 않도록 확인한 뒤 저장합니다. 미리보기와 저장 파일은 같은 변환 함수를 사용합니다. 이미 규격에 맞고 용량 제한 이내인 JPEG는 재압축하지 않습니다.

조원에게 전달할 기준: **720×465 JPG, 사진 안에 흰 테두리·둥근 모서리·글자 넣지 않기, 음식과 소품 주변에 여백 확보, 편집 전 원본 별도 보관.** 피사체 크기는 같은 크기의 메뉴 카드에 나란히 놓고 비교합니다.

고객 목록은 사진 가로를 카드에 맞추고 세로는 비례하여 표시합니다. 사진을 감싸는 별도 테두리·패딩은 없습니다. 옵션 팝업은 기존 높이 170px와 중앙 채우기 표시를 유지하므로 위아래 일부 배경이 더 잘릴 수 있습니다.

Git에 파일을 넣는 것만으로 매장 사진이 교체되지는 않습니다. 매장에는 관리자 API로 게시 파일을 저장하고 사진 키를 연결해야 합니다. 임의의 API 클라이언트가 올린 사진 크기를 서버에서 강제 검사하는 변경은 포함하지 않았습니다.
