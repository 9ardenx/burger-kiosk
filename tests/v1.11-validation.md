재현: `node --test tests/cloud_v12.test.mjs tests/cloud_v18.test.mjs tests/cloud_v19.test.mjs tests/cloud_v110.test.mjs tests/cloud_v111.test.mjs tests/ad_slides.test.mjs`; `node tests/browser_v111.cjs`; 로컬 D1에 마이그레이션 후 `node tests/worker_v111.cjs`. 브라우저는 Playwright/Chrome, Worker는 Sites 체크아웃 의존성이 필요하다. 임시 엔트리는 `.wrangler`에서만 생성하며 공개 소스에 넣지 않는다.

세부 로그/화면/스냅샷은 Git 제외 `data/qa/v1.11/`, `data/backups/v1.11-before-procurement/`에 보관한다. 기존 단일 매장 Python 실행은 변경하지 않았다. 신규 기능은 공개 클라우드 관리자에서 제공한다. 레시피 판매 자동 차감, 본사 창고 재고, 실제 외부 공급사 발주/결제, FCM 알림은 이번 검증 범위에 없다. 실제 규격을 임의 입력하지 않고 본사가 공급 재료를 등록한 뒤 사용한다.
