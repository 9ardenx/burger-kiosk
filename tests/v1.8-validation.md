첫 Python 실행은 상대 import 실행 방식 때문에 3건 중단했고 모듈 경로로 다시 실행했다. 2개 할인 시계 검사에서 단일 매장용 SQL 변환을 추가한 뒤 54개 통과했다. 첫 build-site 실행은 PATH의 npm 부재로 중단되어 동일 package build 스크립트 `node scripts/run-framework.mjs build`로 빌드했다. 로컬 Wrangler 설정 위치/상대 import 문제를 바로잡은 뒤 실제 D1 이전과 Worker를 확인했다. 이 도구 문제를 제품 버그로 집계하지 않는다.

제한: Python은 단일 매장 호환 모드. 공개 PG는 모의 결제 유지. 실제 이메일 인증·최초 매장 연결은 11-27 23:55 사용자 완료 회신과 서버 설정으로 확인. 복구 메일 수신·비밀번호 재설정은 아직 미실행. 구성원 초대는 서버의 이메일 허용 등록이며 초대 메일 자동 발송 기능은 없다.
