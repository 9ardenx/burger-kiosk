Worker: Sites 체크아웃에서 마이그레이션을 `.wrangler/v19-test`에 적용한 뒤 `node tests/worker_v19.cjs`. 검사 진입 파일은 `.wrangler`에만 생성하며 공개 빌드에 포함하지 않는다. 실제 배포 빌드도 완료했다. 상세 로그·화면·스냅샷은 Git 제외 `data/qa/v1.9/`, `data/backups/v1.9-before-franchise/`에 보관한다.

실제 점주 이메일로 임의 초대/계정 생성/비밀번호 변경을 실행하지 않았다. Firebase 실제 메일 수신은 v1.8의 사용자 완료 기록과 구분하며 이번 개설 자동 검사는 임시 인증 제공자로 검증했다. 초대 안내는 복사 기능이고 자동 이메일 발송 기능은 아니다. 운영 PG·푸시·본사 메뉴 변경 일괄 배포는 포함하지 않는다. Python 실행은 기존 단일 매장 호환 모드를 유지한다.
