실행 결과:

- `python -m unittest discover -s tests -v`: 38개 통과(이전 33 + v1.5 5). Python 업무 모듈/SQLite 서비스 검사.
- `node --test tests/cloud_v12.test.mjs`: 19개 통과(이전 15 + v1.5 4). 실제 Worker 처리기 및 메모리 SQLite를 사용하는 API 통합 검사.
- `node tests/browser_v15.cjs`: 6흐름 통과, 미처리 JavaScript 오류 0. 기존 `browser_v12.cjs`, `browser_v13.cjs`, `browser_v14.cjs`까지 총 24흐름 통과.
- `node tests/browser_photos.cjs`: 기존 메뉴 사진 72조건 및 변환·미리보기 검사 통과. 기존 검사에는 첫 화면에서 매장 선택하는 단계를 추가함.
- 운영 Worker 빌드 통과. 새 격리 D1에 0000~0006 마이그레이션 29개 SQL 문 적용 후 실제 workerd/D1/R2 기능 검사 통과.

신규 스키마는 광고 카탈로그와 주문의 nullable `dining_type` 필드이다. 과거 주문을 매장 또는 포장으로 추정해 덮어쓰지 않는다. 구버전 화면의 요청 호환성을 위해 방식 누락을 미기록으로 허용하되, v1.5 고객 화면은 새 주문 전에 선택을 요구한다. 로컬 SQLite는 광고 이미지용 테이블을 메뉴 사진과 별도로 사용한다.

화면 캡처·JSON 결과는 `data/qa/v1.5/`, 사진 회귀 자료는 `data/qa/photos-720x465/`에 보관(Git 제외). 신규 제품 결함은 재현되지 않았으며 기능 추가와 예방 검사는 버그 수에 포함하지 않았다.

제한: 광고 예약 기간·노출 통계·외부 링크 기능은 이번 범위 밖이다. 삭제/숨김은 노출 목록에서 제거하며 저장된 이미지 파일을 즉시 물리적으로 삭제하지 않는다. 광고 변경은 약 15초 조회 주기로 반영된다. 현재 결제는 모의 결제이며 휴대폰 문자 복구는 미적용이다.
